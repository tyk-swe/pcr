# Triage labels

Use these labels on GitHub issues.

| Label | When to apply it |
| --- | --- |
| `needs-triage` | A maintainer needs to evaluate the issue. |
| `needs-info` | The reporter needs to provide more information. |
| `ready-for-agent` | An agent can implement the issue without further input. |
| `ready-for-human` | The issue requires a human to implement it. |
| `wontfix` | The project has decided against taking up the issue. |
