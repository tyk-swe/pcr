# Derive settings labels from their definitions

## Context

Resource diagnostics spelled out preset names already generated by Clap. NDJSON timeout help repeated both the runtime default and the parser range ceiling.

## Decision

Use the parsed preset's Clap value for diagnostic sources. Build the timeout help from the same constants used by dispatch and argument validation. Keep the timeout flag optional so the CLI can distinguish an explicit override from the default.

## Alternatives

Using a Clap argument default would supply a value on invocations without the flag. It would require revisiting format validation and the existing source reporting for the effective timeout.
