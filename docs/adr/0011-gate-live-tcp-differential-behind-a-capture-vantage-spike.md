# Gate live TCP differential behind a capture-vantage spike

ADR 0007 deferred live stateful TCP crafting because the host kernel owns ordinary TCP connections and can reset crafted segments it did not initiate. A cooperating TCP endpoint that accepts connections does not solve that sender-side problem, and it would let the tool claim middlebox Verdicts from a handshake it never honestly made. The safer shape is a capture vantage on the responder side: crafted SYNs are generated by the existing packet workflows, a target-side capture records the segments as seen on the wire, and an offline classifier groups them by a sequence-number Canary. Silence then stays unanswered and never becomes a blocked Verdict.

This spike ships only that capture-side classifier. It defines a sequence encoding where each attempt is `base + variant * 4096 + attempt`, extracts SYN segments from an operator-supplied capture, and reports arrivals and distinct TCP option digests by Variant. It deliberately ships no live TCP campaign command. The gate for one is a two-host lab result showing that responder-side captures correlate with sender attempts at the stated repeat count, that sender-kernel resets are distinguishable from crafted SYNs by tuple and sequence, and that TCP option rewrites reported by the classifier match a capture taken at the sender. Until that evidence exists, a live command would be a sender with unproved Verdicts, so the correct outcome of the spike is to stop here.

Executable retest has the same shape of problem. Evidence bundles and journals bind results, Scope and plan digests, but neither records argv, because recording a full command line would also record local paths and any operator-supplied values that were never meant to leave the engagement record. A tool that claims to re-execute a bundle would therefore be inventing the very inputs it claims to be checking. Until an execution manifest is designed as its own reviewed document, retest support stops at a verified checklist generated from the journal, paired with findings-diff for the rerun results.
