# RUSTSEC-2024-0436 remediation

## Status

- Last reviewed: 2026-08-08
- Status: temporary, CI-audited exception pending a vetted upstream release
- Remediation target: 2026-09-15
- Exception expiry: 2026-10-12 UTC
- Owner: Native networking (`@tyk-swe`)

[`RUSTSEC-2024-0436`](https://rustsec.org/advisories/RUSTSEC-2024-0436.html)
is an informational advisory for the unmaintained `paste` crate; RustSec lists
no patched version. PacketcraftR's exception is limited to this advisory.

## Current exposure and controls

The locked all-feature Linux graph contains this build-time path:

```text
paste 1.0.15
└── netlink-packet-core 0.8.1
    └── rtnetlink 0.21.0
        └── packetcraftr-network 0.5.0-beta.1 (native-route)
```

`netlink-packet-route` and `netlink-proto` provide two additional paths from
`rtnetlink` to `netlink-packet-core`. `paste` is a procedural macro used while
building the Linux route dependency; it is not linked into PacketcraftR.

Verify the complete path with:

```console
cargo tree --locked --all-features -i paste
cargo tree --locked --all-features -i netlink-packet-core
```

`deny.toml` ignores only this advisory, and CI runs `cargo deny check`. The
date in the ignore reason is a maintainer deadline rather than an automatic
cargo-deny expiry, so review must remove the exception by 2026-10-12.

## Decision and next review

The preferred fix is the smallest compatible published update that removes
`paste` from the `rtnetlink` graph. An isolated `netlink-packet-core 0.8.0`
downgrade removed it but was rejected as a downgrade rather than a vetted
upstream remediation. A Git override, vendored fork, or local netlink
replacement would increase the review surface of safety-sensitive route parsing.

Recheck compatible `rtnetlink`, `netlink-packet-core`,
`netlink-packet-route`, `netlink-proto`, and `netlink-sys` releases by
2026-08-15. If no vetted update exists by 2026-09-01, begin a separate review
of maintained published netlink alternatives. Do not extend the exception to
avoid that review.

## Acceptance criteria

The remediation must preserve IPv4/IPv6 route lookup, multipath and preferred
source handling, interface identity validation, route MTU selection,
no-default/native-route/all-feature builds, and Rust 1.96 compatibility.

Before removing the exception, confirm that the inverse tree contains no
`paste` package and run:

```console
cargo check --locked --workspace --no-default-features
cargo check --locked -p packetcraftr-network \
  --no-default-features --features native-route
cargo check --locked --workspace --all-targets --all-features
cargo +1.96.0 check --locked --workspace --all-targets --all-features
cargo deny check
git diff --check
```
