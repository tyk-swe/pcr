Call the Skill tool with "grilling".

Ask every interview question through the harness's default question tool or equivalent when one exists, and ask directly in plain text only when no such tool exists, following the round mechanics in "grilling". The one exception is the final confirmation before acting on the plan, which stays a direct plain-text question.
